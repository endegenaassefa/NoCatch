OpenCluely

Setup Guide — follow the steps in order. It takes about 10 minutes.

Before you start, make sure you have:
• A computer with Windows 10 or Windows 11
• About 3 GB of free space on the C: drive
• Internet (needed for setup and for asking questions)

1 Open the ZIP file

  • Find the file you downloaded, for example OpenCluely-Beta-Setup.zip. It's usually in your Downloads folder.
  • Right-click it and choose Extract All…
  • Click Extract in the window that appears.
  • A new folder opens with two files inside: a setup program and this guide.

2 Double-click the setup program

  • Double-click OpenCluely-Setup-1.1.0-beta-x64.exe.
  • A blue window may appear that says “Windows protected your PC”. This is normal — the app is a test version and doesn't have a paid signature yet.
  • On that blue window, click More info, then click Run anyway.
  • If you see a different warning (for example from your antivirus), always choose Allow, Run anyway, or More info → Run anyway.
Only do this because you got the file from someone you trust. Never click “Run anyway” on a program from a stranger.

3 Wait for it to install

  • A progress bar appears. Wait 1–3 minutes — it is unpacking about 2 GB of files.
  • When it finishes, OpenCluely opens by itself.
  • You'll also see new icons on your Desktop: OpenCluely, OpenCluely (Admin), OpenCluely Exam Mode, and OpenCluely Stop. That's normal.
If the app didn't open by itself, double-click the OpenCluely icon on your Desktop.

4 Get your AI key (one time only)

The app answers questions using DeepSeek, an AI service. You need your own key — like a password that lets the app talk to the AI for you.

  • Open your web browser and go to: platform.deepseek.com
  • Click Sign up and make an account (you can sign up with Google).
  • Click Top up and add a small amount — $5 is plenty. (Answers cost a tiny fraction of a cent each, so $5 covers hundreds of questions.)
  • On the left, click API Keys, then click Create new API key.
  • Give it any name, click Create, then click Copy.
  • Your key starts with sk-. Keep it secret, like a password.

5 Put the key into OpenCluely

  • In the OpenCluely window, click the Settings gear icon.
  • Find the box called “LLM Provider” and choose DeepSeek.
  • Find the box called “DeepSeek API Key”, click it, and paste your key (right-click → Paste, or press Ctrl+V).
  • The app saves it automatically — you can close Settings.
If a welcome window appeared when the app first opened, you can also paste the key there. Same key.

6 Try it with your own files

  • Click the Add files button in the app.
  • Pick one or more PDF or PowerPoint (.pptx) files from your computer.
  • Wait a few seconds while it reads them.
  • Type a question about your files into the chat box and press Enter.
  • The answer appears — and it shows you the exact pages it used.

7 Exam mode (only if your school uses LockDown Browser)

  • Press the Windows key on your keyboard and type: OpenCluely Exam Mode, then press Enter.
  • Windows asks “Do you want to allow this app to make changes to your device?” — click Yes.
  • A protected Cluely window appears on top. During the exam:
  • Ctrl+Shift+S = read the question on your screen and answer it.
  • Ctrl+Shift+V = bring the Cluely window back to the front if the exam browser covers it.
  • When you're done: double-click OpenCluely Stop and click Yes. (Or just restart the computer — that always turns it off.)
If the “Yes” box asks for a password: that's the computer's administrator password. Ask whoever owns the computer. Without it, you can still use Steps 1–6 normally — only exam mode needs it.

“Windows protected your PC”More info → Run anyway (Step 2)
Antivirus warning about the setup fileChoose Allow / Run anyway — it's the unsigned beta
App didn't open after installingDouble-click the OpenCluely Desktop icon
“Configure the selected provider in Settings first”You skipped Step 5 — paste your DeepSeek key
Answers complain about balance or paymentAdd a little credit at platform.deepseek.com (Step 4)
“Not enough space” during installYou need ~3 GB free — empty the Recycle Bin and try again
Ctrl+Shift+S did nothingClick once on the Cluely window first, then press it again
Exam mode asks for a passwordIt needs the computer's admin password (Step 7 note)
You want to remove the appWindows Settings → Apps → find screen-reader-util → Uninstall
Anything else looks brokenTake a screenshot and send it to the person who gave you this ZIP
Privacy: your files stay on your computer. When you ask a question, only the question and a few matching lines from your file are sent to DeepSeek to write the answer.
