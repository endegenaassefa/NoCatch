Sign-out & privacy

Sign-out stops requests and removes saved sign-in on this device. It does not delete server records. The pilot service retains answers and events for 24 hours by default; already-issued access tokens may remain valid until expiry.

Show helper's own backup window
Off (recommended): the shield has no custom UI — answers appear in the Cluely chat window, which stays visible with chat history, question types, typing and mic. On: the root helper also draws its own small unkillable window, which keeps showing answers even if Cluely gets killed mid-exam.
Enter Exam Mode
Push your DeepSeek config to the root shield helper and switch to exam mode — the chat stays on top as your surface while the overlay and settings hide; press ⌃⌥⇧E (or the chat's 🛡️ button) to restore. The helper then captures and answers on its own (⌘⇧Space), unkillable by LockDown Browser.
Requires the shield helper to be running as root. Run sudo bash scripts/install-shield.sh once first — it seeds the shared secret token that locks the helper's socket, so LockDown Browser can't reconfigure or quit it. Then start the helper in a terminal before the exam with sudo -E /usr/local/bin/cluely-shield. The same action is also bound to the ⌃⌥⇧E shortcut — it toggles exam mode armed ↔ restored.
