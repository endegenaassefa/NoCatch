Keyboard shortcuts
Global Shortcuts
Shortcut Action
Ctrl/Cmd + Shift + S Capture screenshot and analyze
Ctrl/Cmd + Shift + V Toggle visibility
Ctrl/Cmd + Shift + I or Alt + A Toggle interaction (click-through)
Ctrl/Cmd + Shift + C Open chat
Alt + R Toggle speech
Ctrl/Cmd + , Open settings
Ctrl/Cmd + Shift + Space Start / stop keystroke capture (configurable in Settings)
While Capturing
Ctrl + Alt + Cmd + Space Open / close the menu (no mouse needed)
Ctrl + Alt + Cmd + 1–6 Switch question skill instantly
Esc Exit capture — typing goes back to your editor
↑ ↓ or Tab Move through the menu
Enter Choose the highlighted item (menu open) · send (menu closed)
Letters Jump to menu items while the menu is open
Unavailable shortcuts are marked above. Use another available shortcut or the app controls.
